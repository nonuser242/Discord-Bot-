## 📜 Amarrada Bot-ka (Commands)
Bot-ku wuxuu leeyahay amarradan gaarka ah ee maaraynta server-ka:

| Amarka | Qeexidda (Description) |
| :--- | :--- |
| `/lock` | Ku xir channel-ka si aan fariimo cusub loo soo dirin |
| `/unlock` | Ka fur xirnaanta channel-ka |
| `/antilink` | Ka shid ama ka dami xakamaynta link-yada (`on`/`off`) |
| `/slowmode` | Ku samee channel-ka xaddidaad fariimaha ah (Slowmode) |
